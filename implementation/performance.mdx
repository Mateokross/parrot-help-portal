Powerbeans widgets are built to have no meaningful impact on your page speed or Core Web Vitals.

## Async loading & page speed

Every widget script (Audio Player, Playlist, Text Summaries) loads **asynchronously** — it runs independently of your page's main thread and critical rendering path, so it never blocks or delays your page render. Widget assets are served from a global CDN and **cached in the browser for 30 days** after a reader's first visit, so returning visitors load the widget without a repeat trip to Powerbeans' servers.

## Preventing layout shift (CLS)

Because the widget injects itself into the page after your initial layout renders, reserve space for it in your CSS ahead of time — otherwise the surrounding content can shift once the widget appears, hurting your Cumulative Layout Shift (CLS) score.

Reserve a minimum height on the player container:

| Configuration | Minimum height |
|---|---|
| Without ads | 90px |
| With ads | 180px |

Set this as a `min-height` on the container element the widget mounts into, sized to match whether ads are enabled for that placement.
